# 🐾 RescuePaws — Pet Adoption & Sighting Platform

RescuePaws is a modern React web application designed to connect pet rescue organizations, foster caregivers, and potential adopters. The platform allows users to browse foster pets, filter listings by species or gender, interact with adoption posts, and submit new adoption or sighting reports.

---

## 🚀 Key Features

* **Interactive Adoption Feed**: Browse foster pet profiles with clean, organized details (age, gender, species, and status).
* **Smart Filtering System**: Filter listings seamlessly by category (Dogs, Cats) and gender (Male, Female).
* **Interactive Engagement**: Live Like counter feature that dynamically updates engagement status per pet.
* **Structured Adoption Form**: Comprehensive **Pet for Adoption / Report Sighting** form featuring:
  * Species selection (Dog/Cat)
  * Identity essentials (Name, Age, Breed, Gender, Status)
  * Image upload dropzone preview
  * Customizable caption text box
  * Foster caregiver & verification status tags

---

## 🛠️ Tech Stack

* **Frontend Framework**: React.js
* **Icons & UI Assets**: Unicode Icons / Custom Styling
* **Styling**: Modern CSS-in-JS (Inline Style Objects) / Responsive Flexbox & Grid Systems
